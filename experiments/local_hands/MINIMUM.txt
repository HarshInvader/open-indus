1. UNIT
   One occurrence (token) in an ICIT record of a W sign that belongs to an eligible variant
   family: a set of >= 2 ICIT (Wells) signs that map to one Mahadevan sign.

2. ELIGIBILITY (lh_lib.load_families, occurrences, apply_floor; count_gate.py implements it)
   Map: experiments/consensus_corpus/out/concordance.json, "primary" (M -> list of W).
   Families: a W sign is exclusive if it is listed under exactly one M sign. The family of M
     is its exclusive W signs, kept if there are >= 2. (W signs shared between M signs, e.g.
     the tree W390/W405 listed under M161, M167, M168 and M169, are therefore out: their
     Mahadevan identity is not one sign.)
   Records: data/icit_texts.jsonl via corpus.load.icit_texts(). Site field not '-', empty or
     'Unknown...'. Non-empty after removing '|' and '#'. One record per distinct
     (site, coarse type, flattened sequence), first in file order (removes moulded and
     duplicate copies). Coarse type = rc_lib.icit_type rule (seal, sealing, tab_moulded,
     tab_incised, tablet, pot, other).
   Variables per token: family, form (the W sign), site, coarse type, period label
     (site|period|phase, only when period is not '-'; compared within one site only),
     prev and next item in the raw sequence: text edge <s>/</s>, line break <lb>, damage <dmg>,
     else the sign, with any W in an eligible family replaced by its family id.
   Hold-out: text families from experiments/split_witness/sw_lib.families(); a record is
     held out when sha256("local_hands:holdout:" + text family id) mod 5 == 0 (about 20% of
     texts, whole near-copy families on one side).
   Floor: a variant is kept if it has >= 10 DEV tokens; a family is kept if >= 2 variants
     survive. Tokens of dropped variants are removed (dev and held-out alike).
   Context pooling (inside each test, no form labels used): per family and side, neighbour
     values with < 5 tokens in the analysed set become one <other> value.

3. STATISTICS (lh_lib.nb_test, pl_test; G = 2 N x conditional mutual information, nats)
   NB, neighbour with place held: strata = family x site x type;
     T_nb = G(form; prev | stratum) + G(form; next | stratum).
   PL, place with neighbours held: strata = family x type x prev x next;
     T_pl = G(form; site | stratum).
   PER (secondary, no bar): tokens with a period label at sites with >= 2 labels;
     strata = family x site x type x prev x next; T_per = G(form; period | stratum).
   Null for each: form labels permuted among tokens inside the test's own strata, 2,000
     permutations, one-sided p = (1 + #null >= obs) / 2001. The stratum holds the other
     factor fixed, so a neighbour effect cannot pass as place and vice versa (checked below).
   Effect size: U_excess = (T - mean null T) / 2 / (N H(form | stratum)) (per side for NB).

   At this minimum the PL arm has power >= 0.90 (rule J, d = 0.20). The NB arm does NOT reach

5. THEORY-BEARING ENDPOINT (finding 2: about 400 signs, about 565 with unseen, at the
   Mahadevan level; README row 2)
   - NB passes, PL fails: variants are contextual (bound) allographs. Mahadevan's lumping
     is right for the tested families; finding 2 unchanged.
   - PL passes, NB fails: variants are local hands (place habits). Lumping is right;
     finding 2 unchanged. paragorth's "set largely by the neighbour" is then not replicated
     once duplicates and the hold-out are applied.
   - Both pass: both conditioned (local spelling rules); finding 2 unchanged.
   - Neither passes (with the power caveat of section 4): the variants are not shown to be
     one sign; they may be distinct signs or free variation. Upper bound on the effect on
     finding 2: + (variants - 1) summed over the tested families, reported as a number of
     signs; finding 2's type call (logo-syllabic) changes only if that bound moves the count
     outside the 95% CI 508-658 for the unseen-inclusive estimate, which no plausible
     family count does. State the bound, do not revise finding 2 on it.
   - Diagnostic caveat fixed in advance (paragorth S-DARK-52.1: neighbour-conditioned choice
     is also what two different signs in one slot show): an NB pass is labelled "contextual
     allograph" only if the families' NB U_excess is above the 95th percentile of 200
     control sets of distinct-sign pairs (two different M signs, each with one exclusive W,
     dev token counts within x0.5-x2 of the family's variants, same family-count). Else
     "neighbour-conditioned, not diagnostic of allography". Same control for PL.

6. HOLD-OUT
   Text families with hash mod 5 == 0 (section 2) are never used for development and are
   read once, for the rule-J replication.

7. BARS (two primary tests, Bonferroni over 2)
   NB pass: dev p <= 0.005 and held-out p <= 0.05. PL pass: the same. PER: no bar.
   Per-family results are exploratory.

8. K0 (planted check first, on real records)
   Before any real statistic: relabel forms of the real dev tokens synthetically (forms
   drawn from each family's dev share, then a PL d = 0.2 plant, then an NBb b = 3 plant on
   the real prev values) and run the frozen code. K0 passes if PL fires on the PL plant
   (dev p <= 0.005), NB fires on the NB plant, neither fires on the null relabel, and the
   cross-test stays silent (p > 0.05) in >= 16 of 20 relabels each.

10. FALLBACK RULES (written in advance; nothing else may change after the count)
   F1. Gate fails: stop. No test statistic on real data. No relaxing of the map, exclusivity
       rule, floor, dedup, hold-out or thresholds. Report as untestable at stated power.
   F2. Gate fails only on families or tokens because exclusivity removed the tree
       (M161/M167/M168/M169 with W390/W405): a union-component family rule may be used only
       under a new study tag with its own MINIMUM hashed before any statistic.
   F3. K0 fails: stop and report; a code fix is allowed only if it changes no rule above and
       is logged with new hashes before any real statistic.
   F4. count_gate.py crashes: a fix that changes no rule or threshold is allowed and logged
       with its new hash in count_gate.md; any other change = INVALID.
   F5. Any frozen file hash differs from section 11 at the count (other than F4): stop.
   F6. Fewer than 200 valid control sets in section 5: use all that exist, report the
       number; with fewer than 50, the allograph label is not assigned.
