sign_type_classifier count gate: minimum, written BEFORE any count. 2026-11-25T18:23Z.
Plan 12, family 3. Label-free counting only: no feature, classifier or accuracy is computed.

Unit counted: a "cell" = one read writing system x one corpus. Cells of one script family
(all cuneiform; all Aegean; all Sinographic, i.e. Chinese characters plus kana or hangul) form
ONE independent family. The held-out unit of the study is the FAMILY, not the cell.

A cell is ELIGIBLE only if all of:
  E1 labels: a per-token sign type (SYL syllabogram / LOGO logogram / DET determinative / NUM
     numeral) comes from edition markup or a published sign list, not from any statistic of the
     text, for >= 90% of clean tokens.
  E2 reading-free sign IDs: each token carries a sign identity that does not encode its type or
     reading (a Unicode glyph, a sign-list number). Reading strings are not sign IDs.
  E3 size: >= 20,000 clean tokens (two disjoint Indus-shape draws of 10,000 tokens).
  E4 two classes: in one 10,000-token Indus-shape draw, >= 20 scored sign types (>= 3
     occurrences) in each of SYL and LOGO.
  E5 licence: open, or local use permitted (local-only data never leaves the machine).
Clean = lines with any damage, restoration, query or illegible mark dropped WHOLE (never
deleted mid-line). Numerals: a group of one numeral unit repeated n times is ONE token whose sign
ID is the group (as an Indus stroke group is one sign); each decimal/sexagesimal place is a
separate token.

MINIMUM:
  F1 >= 3 eligible families, so that leave-one-family-out (LOFO) has >= 3 held-out units with
     >= 2 training families each. With fewer, the study is not run as drafted.
  F2 (stated now, not required) >= 4 families would be needed before a LOFO pass could be
     read as transfer to an unseen family with any family-level confidence; with exactly 3 the
     draft must say LOFO is weak and choose explicitly.
  F3 DET: if DET has >= 20 scored types in fewer than 2 families, DET cannot be held out and
     trained at once, and is dropped from the gated target (record-only).
Indus shape for comparison is counted by the same script from data/m77_texts.jsonl.
