Open Indus Display, for titles in capitals

Decipher the Indus script by 2027

Seals were cut in soft stone, then fired hard and pressed into clay. Thousands of short texts survive. Not one sign can be read yet, and every test of a reading is published here, whether it holds or fails.

Open Indus Text, for sentences and labels

Open Indus Display is for lines set all in capitals: titles, labels and the wordmark. Its capitals and figures are drawn for this project from single strokes, with touches that echo the signs on Indus seals, such as the almond-shaped O and 0 and the small ticks on U.

Open Indus Text is for everything in mixed case: sentences, buttons and menus. It is Instrument Sans with our spacing, because the almond O reads like a zero next to lowercase letters.

This is a first version. The Display capitals are the most finished part. Each cut has about 206 characters, including accented letters and common symbols.

How to use them on a website

Put the four .woff2 files next to your stylesheet and add the rules below. Use Display only where the text is in capitals.

@font-face { font-family: "Open Indus Display"; src: url("OpenIndus-Regular.woff2") format("woff2"); font-weight: 400; font-display: swap; }
@font-face { font-family: "Open Indus Display"; src: url("OpenIndus-Bold.woff2") format("woff2"); font-weight: 700; font-display: swap; }
@font-face { font-family: "Open Indus Text"; src: url("OpenIndusText-Regular.woff2") format("woff2"); font-weight: 400; font-display: swap; }
@font-face { font-family: "Open Indus Text"; src: url("OpenIndusText-Bold.woff2") format("woff2"); font-weight: 700; font-display: swap; }
body { font-family: "Open Indus Text", system-ui, sans-serif; }
h1 { font-family: "Open Indus Display", system-ui, sans-serif; text-transform: uppercase; }

03Files

Research files and the Indus data

All of these are in the public code repository.

  • All the Indus data, in one catalogueEvery source we use: excavation reports, both sign corpora, seal registers, findspots, pottery marks, finds abroad, new finds. Our own tables to download, plus one script that rebuilds the rest from public sources.
  • The public test benchScore a proposed reading the same way as every other key.
  • 100 sealed pre-registrationsEach test, written down and hashed before it ran.
  • 83 closed routesEvery route to a reading tested and ruled out, with what would reopen it.

The Indus text corpus, sign drawings and seal photographs are not ours to republish. The catalogue says where each comes from, and the script fetches the public ones onto your computer.
