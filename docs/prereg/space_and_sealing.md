## Claim restriction (both tests)
T4 claims only an **omission order**: which sign classes disappear first as the seal face shrinks, and whether short texts on small seals are contained subsets of longer texts. It makes **no status, rank or office claim** (the status ladder is closed; STOP list). T6 claims only whether a closer class is enriched on sealings relative to seals at the same sites, and what the die-match rate implies about seal survival.

## T4: what drops when space is tight
Data: ICIT SEAL:S, steatite (or "soft stone"), width x height > 20 mm^2, complete texts (no break, `complete` true). Strata = site x (period|phase string, "-" kept as its own level); strata with one text are dropped. Area enters as log(width x height), centred within stratum. All p-values by permuting log area within strata (10,000 permutations unless stated).

- **P1 (positive control)**: text length rises with area. One-sided p < 0.05. If P1 fails, T4 is uninterpretable.
- **P2 (primary; 8 tests, Holm)**: for each class c, slope of c's **token share** (class tokens / text length) on centred log area. Under uniform thinning (small seals drop signs at random from a common template) every share is flat. Positive slope = share grows with space = class **dropped first** on small seals; negative = class **kept** (core-like). Two-sided, Holm over 8 classes. Power: 80% MDE = 2.8 x null SD, reported per class (per doubling of area).
- **P3 (order replication)**: the 8 P2 slopes are computed separately (a) on catalogue vs metric sites and (b) on the two halves of the rank_ladder ICIT family split (`experiments/rank_ladder/icit_family_split.json`). Null for the Spearman rho between halves: area permuted within strata in both halves (2,000). **Pass** = rho >= 0.5 with p < 0.05 in BOTH comparisons. The omission order is called **replicated** only if P1 passes, at least one class is Holm-significant in P2, and P3 passes.
- **P4 (containment)**: among distinct T4 texts of 1-3 signs, the share that are an ordered (not necessarily contiguous) subsequence of at least one longer distinct complete text on any ICIT seal (SEAL*, any site, allograph-normalised). Null: each core sign of the short text is replaced by a random core sign from the same frequency decile (frame and numeral signs kept in place), 1,000 replicates. **Supported** (short texts are abridgements of attested longer texts with the same core) if one-sided p < 0.05. Descriptive companion (P4b): for each contained short text, the signs that the shortest containing text adds, by class, against that class's share in the containing texts (ratio > 1 = class added = optional). Bootstrap 95% CI over short texts. P4b is consistent with P2 if every Holm-significant P2 class has a ratio on the same side of 1.
- **P5 (area beyond length)**: among 1-3 sign texts, is containment more common on smaller seals, within site x length strata? One-sided (negative slope), p < 0.05. Supports "abridged because of space" over "short by choice".
- **Sensitivities (reported, not decisive)**: s1 drop texts carrying raw W706/W742/W745 (the size-tracking carving variants); s2 one text per family (<= 1 edit or contained copy, `corpus.build._close`); s3 metric sites only / catalogue sites only; s4 site-only strata; s5 single-line texts only; s6 leave-one-sign-out within each class (largest change in slope). Secondary: class presence (not share) vs area, per class, with MDE.

## T6: seals vs sealings
Data: ICIT SEAL* (seals) vs TAG* (sealings), every legible face; distinct (site, class, text).
- **Units**: closer classes use texts with a preserved end (last token not "#"); opener uses texts with a preserved start; other frame classes use all legible texts. A text "has" a class if any of its signs is in the class.
- **Closer classes (primary, 6 tests, Holm)**: jar M342 {W740}; M211 {W520}; M169 family {W390 incl. W405-407}; M12/M15 family {W151 incl. W154/156/161}; M254 {W527}; ticked fish.
- **Statistic**: Mantel-Haenszel OR (sealing vs seal) over strata site x legible-length band (1-2, 3-4, 5+), strata with both seals and sealings. p = permutation of seal/sealing labels within strata (10,000), one-sided for enrichment on sealings; Holm over the 6 closer classes. Depletion p reported descriptively.
- **Support** = a closer class with MH OR > 1 and Holm p < 0.05 on all sites, AND leave-Lothal-out MH OR > 1 with one-sided p < 0.05. Leave-Dholavira-out, Lothal alone and leave-one-site-out ORs reported. If no class is supported and planted power at OR 2 (leave-Lothal-out) is < 0.5 for a class, that class's verdict is **untestable**, not refuted. If power >= 0.5 and it fails: **not supported at stated power**.
- **Sensitivities**: complete texts only; site-only strata; closer counted only as the final sign.
- **Secondary (5 tests, two-sided, Holm)**: opener, connective, title, post-closer, numeral; plus leave-Lothal-out OR.
- **Power**: planted OR 2 and 3 on sealings (seal margins kept, sealing presence drawn at seal odds x OR per stratum), 300 replicates, for jar, M211, M169 family, ticked fish; all sites and leave-Lothal-out.
- **Die matches (estimate, no threshold)**: a complete sealing text matches if the identical normalised text is on a complete seal from the same site; a sealing fragment with >= 3 legible signs matches if all its legible runs occur, in order and contiguously, in one complete seal text from that site. Baseline r = share of seal objects at the site whose text is carried by another seal object there (text recurrence across different dies), weighted by sealing counts. Die-survival estimate f = (m - r) / (1 - r), m = pooled match rate, bootstrap 95% CI over sealing texts. Interpretation fixed now: if the CI includes 0, sealing-seal matches are explainable by recurring texts and say nothing about die survival beyond an upper bound; f near 0 with a tight CI means the dies that made the surviving sealings are almost never among the seals found (seals and sealings sample different populations, e.g. sealings arrive from elsewhere or seals were discarded away from the sealing deposits).

## What would falsify
- T4 omission order: P2 all null with MDE below ~0.02 share per doubling (uniform thinning), or P3 rho < 0.5 (order not stable across measurers/families). Containment: P4 at the null (short texts are different content, not subsets).
- T6: all closer ORs near 1 with power >= 0.5 (sealings are a random draw of seal texts by closer class).
