# Pre-registration: typology of Indus name cores (Q1) and Gulf seal residues (Q2)

Registered 2026-11-14, before any held-out (dev_heldout(version=2)) core was analysed and before any Gulf-set metric was computed. Code: `experiments/typology/` (`corpora.py`, `metrics.py`, `q1_typology.py`, `q2_gulf.py`). Dev exploration logs: `q1_dev.log`, `q1_dev_L2.log`, `q1_dev_N200.log`.

## Q1. Do signs inside Indus name cores recombine like syllabograms or like fixed logographic name elements?

**Core definition (frozen).** From `experiments/functional_reading/readings.csv`: maximal runs of tokens with parse role N or F, outside TITLE-BLOCK/REGISTER/OPENER/CLOSER/TITLE/NUMERAL/COUNT+MEASURE constituents, whose lexicon primary role is NOUN or FISH-CLASS NOUN and whose meaning category is not opener-class / pre-jar title / post-closer; runs do not cross line breaks and runs touching `#` are dropped. Unit = distinct core type. Positional metrics use cores of length 2-3.

**Run (frozen).** `.venv/bin/python experiments/typology/q1_typology.py heldout 200 500 400 3` : N_sub = 200 cores per subsample (held-out has 238 cores of length 2-3), 500 subsamples, natural-length sample N = 400 for whole-word metrics. Every reference corpus is resampled in the same run at the same N with the Indus length mix. "Interval" = 2.5-97.5% of Indus subsamples.

Dev values at N=200 (for orientation; thresholds below were set from them): Indus H_rel 0.935, fixed_excess 0.022, partner_rel 0.871, types/token 0.262, len1_share 0.255, standalone_tok 0.454. Ur III H_rel 0.72, LB words 0.88, LB names 0.72, Chinese full 0.22, Chinese given (length 2 only) 0.85, slot code 0.50.

| id | hypothesis | prediction on held-out | pass threshold |
|---|---|---|---|
| H1a | Signs are **not** fixed-position elements | Indus H_rel mean >= 0.80 **and** upper bound of fixed_excess < 0.10 | both |
| H1b | Indus signs are positionally freer than real name stocks with slot morphology | Indus H_rel lower bound > mean H_rel of Ur III names and of Linear B person names | both |
| H2 | Cores are built of signs that stand alone as whole cores | len1_share lower bound > 0.10 **and** standalone_tok lower bound > the largest reference mean standalone_tok (excluding Indus variants) | both |
| H3 | Signs recur with fixed partners (recurrent compounds) more than in any reference | partner_rel upper bound < 0.93 | |
| H4 | Inventory per token is intermediate between a syllabary and logo-syllabic name spelling | mean LB words < Indus interval and Indus interval < min(mean Ur III, mean Proto-Elamite) types_per_token | |

**Decision rule.**
- H1a + H2 + H3 pass -> "Indus name cores behave as free-order combinations of whole-word signs (logographic or logo-syllabic word signs); syllabic spelling of names is disfavoured." (Not excluded: a logo-syllabic script can spell some names phonetically.)
- H1a fails -> fixed-slot logographic model supported.
- H2 fails with len1_share <= 0.05 and H4 at or below Linear B -> syllabic spelling live.
- Any other combination -> inconclusive.
- 5 confirmatory tests; each is a pre-set interval criterion (no p-value). Strict-noun and loose (numerals/titles kept) core variants are reported as robustness, not confirmatory.

**Known limitation registered in advance.** Dev showed that positional freedom alone does not separate syllabic spelling from free-order logographic compounding (Chinese given names H_rel 0.85; synthetic free-order code 1.0). H1 can only refute the fixed-slot model; H2-H4 carry the syllabic-vs-logographic contrast.

## Q2. Do Gulf round/cylinder seals use a small repetitive sign subset (phonetic spelling of foreign names)?

**Gulf set G (frozen).** Union, deduplicated by sign sequence, in Wells numbering: (a) ICIT texts from sites {Ur, Kish, Susa, Nippur, Failaka, Karzakan, Qala'at al-Bahrain, Luristan, Hajar, Salut, Ra's al-Junayz, Tello, Girsu, Tepe Yahya, Saar, Janabiyah, Tell Umma, Dilmun, Kalba} with type SEAL:R, SEAL:C or SEAL:CY; (b) rows of `sources/paragorth_Indus-/data/gulf_seals.csv` with found_abroad = True and a sequence. Breaks dropped.

**Residue.** Remove person signs (Wells anthropomorph block W090-W175) and numerals (Wells stroke block W001-W059). Residues of length 0 are dropped (count reported).

**Home baseline.** Distinct ICIT texts from all other sites except "Unknown", seals (type SEAL*) only, residue computed identically. 10,000 draws of home residues matched one-to-one on residue length (lengths >= 5 pooled).

| id | prediction (foreign names spelled with a small phonetic subset) | statistic | test |
|---|---|---|---|
| G1 | smaller sign set | pooled residue types / tokens | one-sided, Gulf < home |
| G2 | more within-text repetition | share of residues with any sign repeated | one-sided, Gulf > home |
| G3 | more reduplication | adjacent identical pairs / adjacent pairs | one-sided, Gulf > home |
| G4 | the same few signs recur across texts | mean pairwise Jaccard overlap of residue sign sets | one-sided, Gulf > home |

p = (1 + #draws as extreme) / 10,001. Bonferroni over 4: alpha = 0.0125. Hypothesis "small repetitive phonetic subset" supported if G1 and (G2 or G3) pass; G4 is supporting. Robustness (not confirmatory): confirmed/probable rows only; home round seals as baseline; residue without person/numeral removal; M77 "West Asian finds" vs M77 home seals.

**Descriptive (no test).** Candidate syllabogram set = residue signs in >= 2 distinct Gulf texts, ranked by Gulf/home rate ratio. Name-shape comparison: repetition patterns (AB, AA, ABA, ABB, AAB, ABC, ...) and lengths of Gulf residues vs syllable strings of Ur III Akkadian/Amorite-type names (syllabically spelled names in `ur3_legends`) and Linear B names; and a list of personal names attested with Meluhha in `cdli-meluhha-attestations.json`.
